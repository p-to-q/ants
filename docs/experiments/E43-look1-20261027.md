## Acceptance findings retained with the result

The pilot/control seed-1 comparison of the first 200 non-promotion trial
records matches six positions, with divergence at position seven. The first
six s0 specifications have identical `rel_mse`; charged CPU times differ.
This diagnoses a search-trajectory reproducibility limitation, not a demonstrated
evaluator mismatch. The precise cause is unresolved; neither timing nor a code
change has been established as its cause. Per protocol section 5, the divergence
is reported as a determinism finding, not silently treated as a passed replay
or used to select a new policy. Rejected proposals are absent from trial rows,
so this is an accepted-proposal comparison, not a full attempted-proposal replay.

The protocol's crossing-trial wording and the installed script's `CPU <= B`
filter admit different interpretations of the boundary. A separately labelled
sensitivity includes the first budget-crossing finished trial. All 16 primary
endpoints, the paired median and p-value are unchanged. Preserve the registered
script and report both interpretations; do not rewrite the endpoint after
looking. Repeat this sensitivity at the final look.

The protocol's generic “inconclusive” wording is not a confidence bound on the
true effect. Report the interval and uncertainty above, rather than asserting
that all effects larger than a power estimate have been ruled out.
